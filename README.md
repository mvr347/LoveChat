# LoveChat

[![](https://jitpack.io/v/mvr347/LoveChat.svg)](https://jitpack.io/#mvr347/LoveChat)

Многоканальная система чата для Paper серверов с поддержкой модерации, фильтрации, чат-пузырей и расширенной кастомизацией.

## Описание

LoveChat предоставляет полнофункциональную систему общения для Minecraft серверов:
- **Многоканальное взаимодействие** — отделение глобального чата, команд, подсказок
- **Модерация и фильтрация** — удаление/редактирование сообщений, премодерация ненормативной лексики
- **Визуальные эффекты** — чат-пузыри над головой игрока, иконки статуса, форматирование
- **Управление сообщениями** — редактирование собственных сообщений, удаление спама, история чата
- **Система упоминаний** — @player и @everyone с уведомлениями и контролем доступа
- **Фильтрация контента** — защита от спама, матов, капса, реклам ссылок
- **Персональные настройки** — игнорирование игроков, тихий режим, отключение упоминаний

## Конфигурация

Основной конфиг находится в `config.yml`. Основные настройки:

### Каналы чата

```yaml
channels:
  global:
    display-name: "Глобальный"
    format: "<%player%> %message%"
    color: "#FFFFFF"
    # ... дополнительные опции
```

### Модерация

```yaml
moderation:
  auto-delete-profanity: true      # автоматически удалять ненормативные сообщения
  require-approval: false           # требовать одобрение от модератора
  caps-limit: 70                    # процент капса, при котором срабатывает фильтр
  spam-cooldown-ms: 500             # минимальная задержка между сообщениями
```

### Чат-пузыри

```yaml
chat-bubbles:
  enabled: true
  max-distance: 64                  # расстояние видимости пузыря
  duration-ticks: 100               # длительность отображения
  height-offset: 1.5                # высота над головой
```

### Фильтрация контента

```yaml
content-filter:
  profanity-filter: true            # фильтр ненормативной лексики
  link-filter: true                 # фильтр ссылок (кроме исключений)
  spam-filter: true                 # защита от повторяющихся сообщений
```

## Механика работы

### Отправка сообщения

1. Игрок пишет сообщение в чат
2. Система проверяет **фильтры контента** (матерные слова, ссылки, спам)
3. При нарушении:
   - Если `auto-delete: true` — сообщение удаляется тихо
   - Если `require-approval: true` — сообщение ждёт одобрения модератора
   - Иначе — сообщение отправляется, но помечено/отредактировано
4. Сообщение форматируется согласно выбранному каналу
5. Все игроки, которые не игнорируют отправителя, получают сообщение
6. Если включены **чат-пузыри** — над головой игрока появляется визуальный эффект

### Упоминания (@player, @everyone)

- `@player` — уведомляет конкретного игрока, если тот не отключил упоминания
- `@everyone` — уведомляет всех в чате (требует пермишин `lovechat.mention.everyone`)
- Лимит на количество @everyone в единицу времени для предотвращения спама

### Редактирование сообщений

1. Игрок пишет `/messageedit <message-id> <новый текст>`
2. Система проверяет, что это сообщение игрока или игрок — модератор
3. Отредактированное сообщение отправляется в чат с пометкой [EDITED]

## Установка и сборка

```bash
mvn clean package
```

Скопировать `target/Lovechat.jar` в папку `plugins/` сервера.

Java 21+, Paper 1.21+.

## Структура данных

- **Сообщения** — кэшируются в памяти (Caffeine) для быстрого доступа при редактировании/удалении
- **История игнорирования** — отслеживание активного игнорирования между сессиями
- **Статус каналов** — текущий выбранный канал каждого игрока
- **Кулдауны** — защита от спама (задержка между сообщениями, лимит @everyone)

## PlaceholderAPI

| Плейсхолдер | Описание |
|---|---|
| `%lovechat_channel%` | Текущий выбранный канал игрока |
| `%lovechat_ignored_count%` | Количество игнорируемых игроков |
| `%lovechat_muted%` | Находится ли игрок в режиме молчания (true/false) |

## Технические детали

- **Кэширование сообщений:** Caffeine cache для O(1) поиска по ID при редактировании/удалении
- **Асинхронная обработка:** CompletableFuture для неблокирующей фильтрации и проверок
- **Очистка памяти:** Автоматический cleanup при выходе игрока (ignoredPlayers, silentPlayers, кулдауны)
- **Race condition prevention:** Атомарные операции для кулдаунов @everyone и удаления пузырей
- **Thread safety:** ConcurrentHashMap для всех общих структур данных
